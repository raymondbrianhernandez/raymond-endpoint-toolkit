# Changelog

All notable changes to Raymond Endpoint Toolkit are documented here.

## [0.9.2-beta] - 2026-08-18

### Added

- Full Network Report now generates a timestamped HTML report.
- WinGet Application Update Center.
- View available application updates.
- Update a selected application by package ID.
- Update all available applications with confirmation.
- Refresh WinGet sources.
- Generate an application update HTML report.

### Improved

- Expanded portable maintenance functionality.
- Continued migration of technician-facing reporting toward browser-friendly HTML output.
- Updated project documentation for the current beta feature set.

## [0.9.1-beta] - 2026-08-17

### Added

- Registry Diagnostic / Repair Center.
- Registry health overview.
- Registry key backup and restore workflows.
- User profile registry audit.
- Explorer and Start Menu policy audit.
- Windows Update registry audit.
- Network and proxy registry audit.
- Startup registry audit.
- Security policy registry audit.
- Registry search.
- Registry snapshot and comparison workflow.

### Improved

- Consolidated repair features into the existing Windows Repair / Hardware area to keep the main interface compact.
- Corrected the File Integrity menu label.

## [0.9.0-beta] - 2026-08-17

### Added

- Initial public beta release.
- Network and Wi-Fi troubleshooting tools.
- Windows repair and DISM/SFC functions.
- Hardware and driver reporting.
- System, storage, process, battery, BitLocker, and full diagnostic reporting.
- USB, browser, network artifact, port, service, persistence, authentication, software, and incident-response audits.
- Microsoft Defender maintenance and offline scan workflows.
- Performance analyzer and optimization center.
- Power/sleep and startup performance diagnostics.
- Windows Update repair.
- Driver backup.
- User profile health and Windows shell repair.
